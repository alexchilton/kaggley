# Intro to AI Ethics

Four exercises, lessons 2 to 5. Lesson 1 has no exercise.

Every question in this course is a `ThoughtExperiment` -- `learntools/ethics/`
defines ex2 to ex5 and every class in them has an empty `_solution`. There is
nothing to fill in and nothing that can be marked wrong: credit comes from
running the cell. The notebooks here are therefore byte-identical to `sources/`,
and the only thing that matters is that they run without error.

The fairness exercise trains real models, so it does do work -- it just is not
graded on the answer.
