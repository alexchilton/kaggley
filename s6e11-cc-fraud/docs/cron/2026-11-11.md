On held-out rows the steps the public ladders took (towards megayak's LM, away from the MLP and GB bags) each lose.
Limits: the base is a stacker at its held-out optimum, so every direction is downhill by construction; the real ladder's base files have no OOF; a member's test file is not its OOF column (megayak's test file averages five fold models). The replay does not prove the public files will fall on the private board.
