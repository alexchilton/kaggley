## Decision

Release v29 today with ideas 1 and 2, plus v28's board results and the two v28 number fixes (items 1 and 2 of the 2026-11-13 "For v29" list), and the retitle (item 3).
Reason: the public best moved to a file whose weights are published in full, so it can be rebuilt byte for byte and measured on labelled rows with no GPU training; it is the first ladder file that claims an out-of-fold gain in all five folds, which is the question a reader of the top notebooks has.

What each arm changes, stated before the offline run (`scratch/banks/v29_1114/sim29.py`, header):
- **Arm A (the 0.95388 file).** No model changes. The file is rebuilt from areebbb's weights (87 members, base = 0.95370 file + LM step); its mix is replayed on out-of-fold rows the way goodpjw2008 does and compared with our wide stacker's held-out score (split 7). It is "better on labelled rows" only if the replay beats our held-out stack; the replay is in-sample, so a win would still be optimistic.
- **Arm B (the move on our stack).** The same weights applied with our held-out stack as the base. It wins only if the 87 members carry information our label-fitted stack lacks; the weights were chosen on these rows against another base, so a gain is an upper bound and a loss is informative.
- **Arm C (board files).** 90/10 and 50/50 of the 0.95388 file with our wide stack; our wide stack + the bold move.
